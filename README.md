# Агрегатор квиз-игр — Караганда

Собирает расписание с четырёх сайтов:

- Квиз, плиз! — https://krg.quizplease.com/schedule
- Шейкер Квиз — https://karaganda.shakerquiz.ru/#games
- Мохито Квиз — https://krg.mohito-quiz.com/games
- Смузи Квиз — https://krg.smuzi-quiz.com/games

## Почему нельзя просто спарсить requests + BeautifulSoup

Все четыре сайта — это JS-приложения (Nuxt / Next.js / Tilda). Само
расписание игр подгружается в браузере через JavaScript уже после
загрузки страницы, в исходном HTML его нет. Поэтому нужен либо доступ
к внутреннему JSON, который иногда встроен в страницу, либо настоящий
браузер (Playwright), который выполнит JS и покажет итоговую страницу.

## Установка

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

## Запуск (шаг 1 — разведка)

```bash
python scrape.py
```

Скрипт для каждого сайта:
1. Пробует скачать голый HTML и найти встроенный JSON-стейт
   (`__NUXT_DATA__` / `__NEXT_DATA__`). Если получилось — браузер не
   нужен, результат сохраняется в `debug/<site>_embedded.json`.
2. Если JSON не нашёлся — открывает страницу в headless Chromium,
   ждёт полной отрисовки и сохраняет:
   - `debug/<site>_rendered.txt` — весь видимый текст страницы,
   - `debug/<site>_rendered.html` — полный HTML после рендера.

## Шаг 2 — присылаете мне результат

После первого запуска пришлите мне файлы из папки `debug/` (можно не
все — достаточно кусков, где видно карточки игр: дата, время, бар,
цена, ссылка на запись). По ним я допишу точный парсер для каждого
сайта, и финальная версия скрипта будет сама вытаскивать дату/время/
место/цену и печатать готовую сводку по дням недели — без ручной
работы каждый раз.

## Дальше

Когда парсинг под каждый сайт будет готов, можно:
- гонять скрипт по расписанию (cron / Task Scheduler) раз в день,
- собирать результат в HTML-страницу или отправлять в Telegram/почту.
Скажите, какой формат сводки вам удобнее — сделаю следующим шагом.

## Телеграм-бот

Бот отвечает на команды по запросу:
- `/today` — квизы на сегодня (или `/today 16.08` — на конкретную дату)
- `/week` — квизы на ближайшие 7 дней

Архитектура — две независимые части, обе бесплатные:

1. **Сборщик (`scrape.py` + `.github/workflows/scrape.yml`)** — гоняется
   по расписанию на **GitHub Actions** (по умолчанию раз в 6 часов),
   парсит все 4 сайта и коммитит `schedule.json` обратно в репозиторий.
   GitHub Actions даёт достаточно ресурсов, чтобы без проблем запускать
   headless Chromium (для сайтов без встроенного JSON).

2. **Бот (`bot/bot.py`)** — лёгкий Flask-сервис на **Render.com**
   (бесплатный тариф). Сам ничего не парсит — при каждой команде просто
   скачивает актуальный `schedule.json` напрямую с GitHub (по прямой
   ссылке на raw-файл) и отвечает. Поэтому ему не нужен браузер и
   почти не нужны ресурсы — идеально ложится в бесплатный тариф.

### Шаг 1 — выложить репозиторий на GitHub

```bash
git init
git add .
git commit -m "Quiz aggregator + bot"
git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
git push -u origin main
```

GitHub Actions запустится автоматически по расписанию, либо можно
запустить вручную: вкладка **Actions** → workflow «Обновить расписание
квизов» → **Run workflow**. После первого успешного запуска в репозитории
появится файл `schedule.json`.

Прямая ссылка на него будет такой:
```
https://raw.githubusercontent.com/<ваш-логин>/<репозиторий>/main/schedule.json
```
Она понадобится на следующем шаге.

### Шаг 2 — создать бота в Telegram

1. Напишите **@BotFather** в Telegram → `/newbot` → следуйте подсказкам.
2. Получите токен вида `123456789:AA...` — он понадобится дальше.

### Шаг 3 — задеплоить бота на Render

1. Зайдите на https://render.com, зарегистрируйтесь, «New» → **Web Service**.
2. Подключите ваш GitHub-репозиторий.
3. **Root Directory**: `bot`
4. **Build Command**: `pip install -r requirements.txt`
5. **Start Command**: `gunicorn -w 1 -b 0.0.0.0:$PORT bot:app`
6. В разделе **Environment** добавьте переменные:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather
   - `SCHEDULE_JSON_URL` — ссылка на raw `schedule.json` из шага 1
7. Нажмите **Create Web Service** и дождитесь деплоя. Скопируйте
   публичный URL сервиса (вида `https://your-bot.onrender.com`).

Бесплатный тариф Render «засыпает» после ~15 минут без запросов — первое
сообщение после паузы придёт с задержкой в несколько секунд, дальше
работает быстро.

### Шаг 4 — подключить бота к Telegram (webhook)

Выполните (подставив свой токен и URL с шага 3):
```bash
curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://your-bot.onrender.com/webhook"
```
Ответ должен быть `{"ok":true,...}`.

Готово — пишите боту `/today` или `/week`.
